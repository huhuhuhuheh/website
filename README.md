Hi! this is the main (and fresh) website!!!!

You can visit it [here](https://ehis.gay)!

## building

Needs node 22+ (whatever the build image uses, 22 is safe)

```bash
npm install      # install the deps
npm run dev      # run it locally
npm run build    # build into dist/
npm run preview  # preview the build
npm run licenses # regenerate src/data/licenses.json
```

This website is most-used for Cloudflare Pages, hosting it somewhere should change or break stuff, otherwise you deploy it [here](https://www.cloudflare.com/products/pages/) (or run it locally on your machine)
